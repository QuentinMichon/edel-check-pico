# dhcpserver

Repris tel quel de pico-examples (`pico_w/wifi/access_point/dhcpserver/`), lui-meme issu
du projet MicroPython. Licence MIT, copyright Damien P. George, en-tete conserve dans le
fichier source.

Aucune modification. Ne pas le reformater : le garder identique a l amont permet de
reprendre un correctif en amont sans avoir a le rejouer a la main.

Il sert au mode point d acces : un telephone qui rejoint le boitier a besoin d une adresse
IP, et rien dans le SDK ne la lui donne.
